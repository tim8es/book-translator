# Source-aligned repetition recovery

This file opts the pinned workflow into a source-aligned correction preflight.
The previous source-neutral repetition guard remains authoritative for older
workflow revisions, plain text, missing/mismatched/duplicate marker IDs or
oversized inputs. For exact aligned source-owned blocks, new repeated phrases
inside a block still fail. Cross-block repetition may reach independent
review only if it occurs once per involved target block and all corresponding
source blocks share an exact five-word sequence. This is not proof of
translation equivalence; the independent candidate gate (or block review)
and canonical full literary review remain mandatory. No marker/anchor,
acceptance or PASS requirements are relaxed. A shared source phrase may be
unrelated to the candidate, so independent review must detect that case.

New reviewer findings must be locally actionable, with anchors containing
the offending words and distinct IDs for noncontiguous defects. Existing
lineage is retained; no grouping or artificial closure of unresolved defects.
Missing-patch typed repair focuses on a single finding.

The first two long-agent trials failed; qualification is required before
production admission. No existing book revision is upgraded by this change.
