# Long-unit Pi agent qualification

Opt-in synthetic profile, run from an immutable executor checkout:
`python automation/quality_qualification.py --revision <sha> --profile long-agent --output /secure/long.json`.

The fixture contains one original-XHTML chapter with 26 distinct patterned
ledger entries and an inert raster asset. Real extraction must retain unique
protected block markers and fall within optional planning size bounds before
any model call. It is a technical alignment and coverage stress fixture, not
a representative literary novel. The actual Pi runner uses at most 60 counted
calls, followed by one independent full-unit audit. A successful translation
alone is insufficient: the latest accepted artifact must have current,
hash-bound accepted agent advice, not a missing/invalid/reserved decision or
fallback. Either admitted strategy may be selected; this does not prove both
strategies were exercised. Provider independence is not established by this
test. No real book state or production flags change. Private workflow
admission of this new profile must be explicitly enabled after CI.
